SC-CMFB TOPOLOGY (replaces ideal E1; control node = Vbcm -> gates of Mn5.2,Mn7.2)
  C_C  (continuous sense/hold) = C7,C8 = 1.25 pF each  Voutp/Voutn -> Vbcm
  C_CM (switched sampling)     = Cs1,Cs2 = 0.50 pF each
       phi1 (reset/sample): Cs charged between Vcmr(0.9) and Vbn(0.624) = 0.276 V
       phi2 (amplify)     : Cs placed Vout -> Vbcm (parallel C_C), refreshes DC
  8 ideal switches  .model SWCM SW(Ron=10 Roff=1e9 Vt=0.9 Vh=0)
  clocks: non-overlapping 20 MHz (50 ns period), phi1 [1,24] ns, phi2 [26,49] ns
  Vcmr = 0.9 V (ideal, bias class);  bias plate ref = Vbn = 0.624 V
  Weak DC helper (OP/AC only): Bhelp Vh 0 V=V(vcmavg)-0.9+V(Vbn) ; Rhelp Vh Vbcm 100Meg
       vcmavg = R1,R2 large-R output average (true CM sense); R1=R2={Rbig}=100G
       -> sets DC bias point exactly (CM=0.900 V); BW ~ 0.6 kHz << signal band (faq-allowed)
  Static current added by CMFB: 0  (clocks draw 0 A; helper draws ~0.5 pA)

  SCHEMATIC HYGIENE (2026-06-28): every CMFB element is a DRAWN symbol
  (sw/cap/voltage/bv/res/current) joined by real WIRES; net-label FLAGs only for the
  sheet-spanning nets Voutp/Voutn/Vbcm/Vbn (+ ground, + vcmavg for the Bhelp expr).
  ap/bp/an/bn switch+cap clusters wired by buses; phi1/phi2/vcmr distributed by wired
  trunks to Vphi1/Vphi2/Vcmr. All directive .param/.model moved INSIDE the params box.
  Boxes "Switched-Capacitor CMFB" + "DC-Bias Helper"; core annotation
  "Ideal CMFB"->"SC-CMFB (Vbcm)"; artifact V(Voutp2,Voutn2) .meas chain pruned.
  Behavioural Bhelp (true-CM sense) regulates .op CM to 0.900 V; an earlier VCVS
  helper (Ehelp, sensing constants) had read 0.914 V -- corrected.

  PLACEMENT (revised 2026-06-28): the whole wired CMFB block (helper + switched net)
  is placed in the CLEAR FAR-RIGHT area (x>4512, right of the opamp core) in all three
  files. An earlier version drew it in the cramped LEFT column; in the .ac bench that
  column also holds the loaded replica + feedback, and an unintended WIRE CROSSING there
  merged a CMFB internal node with replica wiring -> a CM->diff leak (output |CM|~0.019
  for a differential drive) that made the .ac read GBW=260.4 MHz. That 260.4 was a
  LAYOUT ARTIFACT, not physics: a symmetric SC-CMFB injects equal/opposite C_C charge for
  a diff signal so Vbcm cannot move -> diff GBW must equal the ideal-CMFB case. The
  far-right redraw (clear of all other wiring) gives CM->diff leak ~1e-13 and the correct
  GBW=264.4 MHz. Lesson: verify CM->diff leak ~0; never trust a GBW from a layout whose
  wires share a column with other circuitry. Box rectangles are sized to contain the
  RENDERED net-name / instance labels (which overhang pin points ~65 px; tran source
  value labels are long PULSE() strings needing ~500 px extra right margin), not the
  bare pin bbox -- otherwise borders clip the labels.

  differential disturbance     : max|Voutp-Voutn| = 0  (CMFB orthogonal to diff mode)
  Vbcm regulation range        : 595 .. 627 mV (stays valid; devices in sat)
