1. CURRENT-REUSE MIGRATION (the headline)  -- DONE, VERIFIED
--------------------------------------------------------------------------------
   The NMOS-only input pair was made COMPLEMENTARY (Ryu 2007 current-reuse): the two top PMOS
   current sources Mp1.2/Mp3.2 (gate was Vbp) are re-wired as a PMOS INPUT pair (gate = Vip/Vin),
   sharing the SAME input as the NMOS pair Mn3.2/Mn4.2 at the same fold nodes Vgpn/Vgpp. Their
   transconductances now ADD: g_m,total = g_m,n + g_m,p for one current path (no extra branch).
   This is a pseudo-differential complementary input (no PMOS tail -> no headroom cost on 1.8 V).

   Schematic change: ONLY two gate re-wires (Mp1.2 -> Vip, Mp3.2 -> Vin); both PMOS devices were
   already drawn -> satisfies the 6-pt "real drawn components" rule with no new symbols. The
   PMOS input is biased in MODERATE inversion (Vsg = 0.6 V, gm/ID = 12) by setting the input
   common-mode (virtual-ground) to 1.2 V -- a deliberate design choice realized in the SC network
   by the amplify-phase far-end (Cin bottom-plate) reference CM = 1.275 V  [far = (5*vg - Vout_CM)/4].
   ** Caveat (honest): the pseudo-diff PMOS current is CM-sensitive; the input pair is only valid
      at the CM it was sized for (vg = 1.2 V). The real feedback MUST deliver vg = 1.2 V via that
      reference; at a different CM the input pair would need re-sizing.

   g_m,n(Mn3.2) = 6.79 mS, g_m,p(Mp1.2) = 5.66 mS  ->  g_m,total = 12.45 mS  (>= 12.2 for GBW)
   I_pin(Mp1.2) = 470 uA, I_nin(Mn3.2) = 334 uA -> I_cas(fold/output) = 136 uA. Tail 668 uA.

   .param (cr, both core + AC): Mn34=210 Mn12=42 Mn56=11 Mn78=11 Mp13=145 Mp24=38 ; Cin=5p ;
   V5=V6=1.2 (input CM) ; gain-boosters scaled 2x the Phase-4 bias (see step 4).

   VERIFIED (cr_ac.asc, A0/GBW/PM from UNLOADED V(voutp)-V(voutn), beta=1/5):
     A0  = 106.66 dB     (>= 78, +28 dB margin)
     GBW = 272 MHz       (f_u = 54.3 MHz -> amp GBW f_u/beta = 272 MHz; ~264 target)
     PM  = 88.0 deg      (>= 60)
   VERIFIED (cr.asc .op): all FETs saturated, output CM = 0.898 V (G=12 helper pins ~0.9).

4. GAIN-BOOSTER DOUBLET (the binding settling limiter)  -- managed
--------------------------------------------------------------------------------
   At the verified bias the high-accuracy (78 dB) settling tail was limited NOT by pure slew but
   by the gain-booster pole-zero DOUBLET (a ~1.5 mV residual, tau_tail ~5 ns) -- the exact risk
   the Phase-4 doc flagged for "Phase-5 revisit". Scaling the booster bias to push the doublet
   beyond w_u (Binkley) is sharply non-monotone:
        1x boosters -> A(25ns) = 62.5 dB ;  2x -> 77.2 dB (best) ;  2.5x -> 59 dB (overshoots, rings)
   -> 2x is the optimum (scale_boosters.py). Raising the OUTPUT branch current (I_cas) for faster
   slew BACKFIRES: the bigger output devices add cascode capacitance that the boosters cannot
   out-run, re-opening the doublet (I_cas 136->280 uA dropped A(25ns) to 55-66 dB). Reducing C
   (5->4 pF) also lowered PM and hurt. So the FINAL point is lean I_cas (136 uA) + 2x boosters + C=5p.

   TWO MORE bounded closure attempts (the input-gm + booster-compensation axes) -- both FAILED:
     (a) raise input g_m (Mn34 210->257, Mp13 168 to HOLD I_cas) to shrink linear tau: A(25ns)
         DROPPED to 71.4 dB and tau GREW to 3.50 ns -- the larger NMOS-input drain cap at the fold
         node re-opened the doublet, exactly like the I_cas bumps (the hope it'd load BB less was wrong).
     (b) booster COMPENSATION via speeding ONLY the signal path 1.3x (CMFB left at 2x): tau dropped
         to 3.08 ns (booster faster) but A(25ns) = 71.3 dB -- the signal-path/CMFB current mismatch
         hurt the booster's own settling. -> 77.2 dB (lean + 2x all) is robustly the optimum; every
         g_m/current/cap addition re-opens the doublet. This is a genuine Class-A limit, accepted.

5. SETTLING (Deliverable 4)  -- NEAR-MISS (honest)
--------------------------------------------------------------------------------
   step at amplify-phase start; Vout_max = 0.9 V diff; vg = V(vip)-V(vin); offset(1/beta)=14.5 dB.
     A(25 ns)    = 77.2 dB     (spec >= 78  -> SHORT by 0.8 dB)
     Abeta(25ns) = 62.7 dB     (spec >= 66  -> SHORT by 3.3 dB; the binding line)
     T30 = +9.4 ns, T38.69 = +12.2 ns, tau = T38.69-T30 = 3.289 ns
   ** The design REACHES 78 dB / 66 dB at ~26.5 ns -- i.e. ~1.5 ns (6%) past the 25 ns window. **
   Root cause: Class-A folded output slews at I_cas/C_L = 136uA/5pF = 27 V/us; ~15 ns of the 25 ns
   budget is spent slewing 0.45 V/side, leaving ~10 ns (~3 tau) of linear settle -> 77 dB, not 80.5.
   Levers to fully close (NOT taken, each has a cost): Class-AB output stage (decouples slew from
   quiescent current); separate sink-vs-cascode sizing (more slew current, same booster-sensed cap);
   smaller C with the SNR headroom below; finer booster tune. See figure report/figures/cr_d4_settling.png.

6. NOISE (Deliverable 5)  -- PASS
--------------------------------------------------------------------------------
   .noise differential output, log018.l (1/f from 10 kHz), integrated 10 kHz - 100 GHz:
     Vn,amp  (term 11, simulated)                      = 209.5 uV   (<= 225 uV budget)
     Vn,kT/C (term 10, hand 2*(1/beta)^2*kT/Cin, Cin=5p)= 203.5 uV
     Vn,tot  (term 12, sqrt(amp^2 + kT/C^2))           = 292.1 uV
     SNR = 20*log10(0.636 / 292.1u) = 66.76 dB         (spec >= 66  -> PASS, +0.76 dB)
   The current-reuse high input g_m keeps the amplifier-noise share at ~the kT/C level (50/50 split).
   Figure: report/figures/cr_d5_noise.png.  Dominant devices: input pair (Mn3.2/Mp1.2) + NMOS sinks.

--------------------------------------------------------------------------------
