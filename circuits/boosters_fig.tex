% ===========================================================================
%  GAIN-BOOST AUX-AMPLIFIERS — the two folded-cascode regulation amps of the
%  current-reuse core (design/current-reuse/folded_cascode_cr.asc).  SHARED
%  drawing for D2 (node voltages, \showIfalse) and D3 (branch currents,
%  \showItrue); the thin boosters_v.tex / boosters_i.tex wrappers set the mode.
%
%  To stay report-grade readable each booster is drawn as ONE differential
%  HALF (one input device, fold node, cascode, load, sink -> the output node),
%  with the shared reference-pinned CMFB drawn once in its own separated column.
%  The output node both drives the main-amp cascode gate and is sensed (with
%  its mirror-half output) by the 100 MOhm CMFB averager.
%
%   Booster A : PMOS-input folded cascode, senses the main BOTTOM fold node
%               Vgn+ (0.190 V), output Vnl (0.825 V) -> main NMOS cascode gate.
%   Booster B : NMOS-input folded cascode, senses the main TOP fold node
%               Vgp- (1.533 V), output Vpr (0.850 V) -> main PMOS cascode gate.
%
%  CMFB (A pinned to Vcn, B to Vcp): PMOS-mirror / NMOS-diff-pair amp.
%  Bulk: NMOS->GND, PMOS->Vdd (not drawn).  Values from the verified .op.
% ===========================================================================
